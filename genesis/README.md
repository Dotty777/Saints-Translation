# Genesis — Bespoke Saints English Translation

All 50 chapters (1,531 existing verse units) completed as an editorial pass and saved and read back on the WordPress staging site on 14 October 2026. 1,169 verse units changed; 362 retained their wording. This is a provisional reading edition, not a fully verified critical translation.

- **Genesis 1–11:** exact accepted Bespoke PDF benchmark, normalized only for extraction/layout.
- **Genesis 12–50:** individually reviewed English revision. Rahlfs–Hanhart 2006 is the user's authorized provisional base. Selected passages were inspected in the [German Bible Society running text](https://www.die-bibel.de/en/bible/LXX/GEN.1). The full apparatus and Göttingen text were not obtained or collated.
- **Policy:** the newer *Bespoke Saints English (1).pdf* prevails over the earlier *Saints English Founding Style Guide*. Thou/Thee/Thy address God directly; ordinary address uses you/your. Restrained archaism, images, meaningful repetitions, number, tense, names and source distinctions are preserved. Notes are separate from Scripture.
- **Preservation:** original page content is in the backup archive. All existing verse anchors, links, chapter navigation, original notes and study-script content passed preservation checks. The Genesis index now describes the revised edition. The Saints Translation literal-smooth and other comparison streams were not edited. No live-site changes were made.

The accepted benchmark was applied without claiming those questions resolved.

Existing Greek-based numbering is retained, including no separate 31:51 or 35:21 and 33 verse units in chapter 32. Genesis 11:13 retains the Cainan material within its existing anchor. Genesis 49 retains the existing poetic line breaks.
